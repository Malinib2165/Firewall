# Firewall
A basic firewall simulator that filters incoming and outgoing traffic based on predefined rules.

## Features
*Blocks specified IP addresses*
*Blocks specified ports*
*Supports incoming and outgoing traffic checks*
*Easy to customize*

## How to Run
python firewall.py

## Example
IP: 192.168.1.100
Port: 80
Direction: incoming

Output:
[BLOCKED] incoming traffic from/to IP: 192.168.1.100
